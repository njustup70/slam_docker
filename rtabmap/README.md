## 仓库介绍
- 此模块基于 RTAB-Map (Real-Time Appearance-Based Mapping) 进行建图和定位。
- 支持 RGB-D 相机、激光雷达以及多种传感器的数据输入，适用于同时定位与建图（SLAM）任务。
- 提供了地图构建、闭环检测、实时定位等功能，适用于机器人自主导航和环境感知。

## 仓库链接
### [rtab_map](https://github.com/introlab/rtabmap)  
- 官方仓库，包含了RTAB-Map的源码和文档，支持多种传感器和机器人平台。
